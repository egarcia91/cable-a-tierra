# Conventional Commit

Cada vez que se decide hacer un commit a git vamos a accionar este skill.

## Paso 1 — Ver las diferencias 

- ejecutar el comando git diff para ver los archivos afectados por el commit
- detallar para que se hacen los cambios y en que archivos
- describir si se está agregando un nuevo archivo, eliminando uno, o si se está modificando uno ya existente
- tomar la decisión si corresponde la convención de fix, feature, refactor.
